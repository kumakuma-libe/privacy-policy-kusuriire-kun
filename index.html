プライバシーポリシー

最終更新日: 2026年8月19日 ／ 対象バージョン: 4.9.5

本プライバシーポリシーは、Chrome拡張機能「薬入れくん」（以下「本拡張機能」）における ユーザーデータの取り扱いについて説明します。

本拡張機能は、医師・医療従事者が自身の業務で使うことを想定したツールです。 紙・PDF・画像に書かれた処方内容を読み取り、画面で確認・修正したうえで、 電子カルテの処方欄へ入力する作業を補助します。 ユーザーが自分で選んだ画像やファイルだけを処理します。 保存・確定の操作は行いません。入力後の内容の確認と保存は、必ずユーザー自身が行います。

1. 単一の目的（Single Purpose）

本拡張機能の唯一の目的:
ユーザーが指定した処方内容（お薬手帳・処方箋・調剤結果などの画像やPDF）を読み取り、 画面で確認・修正したうえで、電子カルテの処方欄へ入力することです。
本拡張機能は、この目的以外の機能（広告表示・ユーザー追跡・SNS連携・第三者へのデータ販売・ 閲覧履歴の収集など）を一切持ちません。

2. 拡張機能が扱うデータ（収集する情報の種類）

本拡張機能は、ユーザーが読み取りまたは入力を実行した時にのみ、以下のデータを処理します。 Chrome ウェブストアのデータ使用フォームで申告する分類に合わせて開示します。

Chrome ウェブストアの分類 本拡張機能における具体的内容
ウェブサイトのコンテンツ ユーザーが読み取りの対象として指定した画像・PDF そのもの。取得の方法は次の4つで、 いずれもユーザーがボタンを押した時にだけ取得されます。
①現在開いているタブの表示部分のキャプチャ（chrome.tabs.captureVisibleTab）
②上記キャプチャからユーザーがマウスで選択した範囲の切り抜き
③ユーザーが選択したローカルの画像ファイルまたはPDF
④ユーザーが入力欄に貼り付けた画像のURL（そのURLへ画像を取りに行きます）
あわせて、電子カルテ（digikar.jp）の処方画面で、薬を検索したときの候補の一覧 （薬剤名・規格・用法の文字）と、入力した処方行の並びを読み取ります。 これは「どの薬を選ぶか」「どのまとまりに入れるか」を決めるために必要な範囲に限られます。
また、処方行に付いているコメント欄の文字を読み取ります （前の処方から残ったコメントを消すために必要です。読み取った内容は画面内で完結し、 外部へ送信することはありません）。
画面の作りが変わったときに調べるための処理も持っていますが、 入力欄の種類と目印だけを見て、入力された値は読みません。
患者の氏名・生年月日・患者番号・カルテ本文を読み取る処理は持っていません。
個人を特定できる情報／健康に関する情報 本拡張機能は、氏名や生年月日などをそれと分かる項目として取り出す処理を持っていません。 AI への指示文で明示的に禁止しており、処方として整理された結果については、 万一返ってきた場合もコード側で破棄します。 ただしAIが書き起こした文字（自由文）については、指示文での禁止のみとなります。
また、ユーザーが選んだ画像に氏名・日付・処方内容などが写っていれば、 その画像は画像のまま Google の Gemini API へ送信されます（第5章）。
処方内容（薬剤名・用量・用法）は健康に関する情報にあたります。 どの画像を処理するかはユーザーが選択するため、個人情報を含む画像を扱うかどうかは ユーザーの判断と責任によります。
認証に関する情報 ユーザーが登録する Google Gemini API キー（Google 社が発行し、ユーザー自身が取得したもの）。 ユーザーの端末内（chrome.storage.local）にのみ保存されます。 開発者のキーは使用せず、開発者へ送信されることもありません。

本拡張機能は、以下のデータを 収集しません: 氏名・生年月日・住所・電話番号・患者番号などを項目として抽出する処理、位置情報、閲覧履歴、検索履歴、 金融情報・決済情報、生体情報（指紋・顔画像など）、ウェブサイトのログイン情報。

3. データの保管場所と保持期間

保存先はすべてユーザーのブラウザ内です。 開発者が運営するサーバーは存在しません。

  • 画像・PDF・読み取った処方内容：保存しません。 読み取りと入力の処理中だけメモリ上に存在し、サイドパネルを閉じるか 「読み取り直す」を押した時点で破棄されます。ディスクには書き込みません。
  • Gemini API キー・使用するモデルの選択（chrome.storage.local）： ユーザーが変更または削除するまで保持されます。
  • 処理中の一時情報（キャプチャ対象のウィンドウ番号、処理中かどうか、 および画面に出すお知らせの文言。エラーが起きたときは、その理由の文が入ります）： chrome.storage.session に置かれ、ブラウザを閉じた時点で消えます。 ディスクには残りません。
  • 保持期間：上記いずれも、ユーザーが削除するか拡張機能をアンインストールするまで 端末内に保持されます。開発者側にはいかなるデータも保持されないため、 開発者側での保持期間の定めはありません。

4. 拡張機能が要求する権限と用途

本拡張機能が manifest.json で要求する権限と、その用途は以下のとおりです。 いずれも本拡張機能の単一の目的を達成するために必要最小限のものです。

権限 用途
activeTab ユーザーがボタン、またはキーボードショートカット（既定: Windows は Ctrl+Shift+5、Mac は Command+Shift+5）を押した時に限り、 現在開いているタブの表示部分を画像として取得するため。
scripting 次の2つのために使用します。①範囲選択のとき、マウスで範囲を囲むための透明な操作画面を ページ上に重ねるため。②電子カルテの処方画面で、読み取った処方を入力するための部品を 読み込ませるため。読み込むのは拡張機能に同梱したスクリプトのみで、 外部から取得したコードは実行しません。
storage Gemini API キーと設定をブラウザ内に保存するため。および処理中の一時情報を セッション（ブラウザを閉じると消える領域）に置くため。
sidePanel 読み取った内容の確認・修正画面を、カルテを開いたまま横に並べて表示するため。
ホスト権限 https://digikar.jp/* 電子カルテの処方画面で、薬の検索候補を読み取り、選んだ薬・数量・用法・日数・コメントを 入力するため。保存・確定・会計に関わる操作は行いません （押す対象を薬の候補と用法の選択に限っており、余白を押すときもボタン・リンク・入力欄は 避けるようにしています）。
ホスト権限 https://generativelanguage.googleapis.com/* Google の Gemini API へ画像を送信して処方内容を読み取るため。
任意のホスト権限 <all_urls> インストール時には要求しません（任意の権限として宣言しています）。 画面の読み取りに必要なため、サイドパネルを開いたときに許可のご案内を表示しますが、 許可するかどうかはユーザーが選べます（許可の確認画面が出るのは、ユーザーが 「許可する」を押したときだけです）。 許可しなくても、ファイル選択による読み取りと、電子カルテ画面での利用はできます。 許可した場合も、動作するのはユーザーがボタンを押したときだけで、 閲覧内容を継続的に読み取ることはありません。

5. 外部サービスへのデータ送信（第三者提供）

本拡張機能は、開発者が運営するサーバーへのデータ送信を一切行いません。 外部への通信は、次の2つだけです。

5-1. Google Gemini API（generativelanguage.googleapis.com）

  • 実行タイミング：ユーザーが Gemini API キーを登録し、読み取りを実行した時のみです。 自動的な送信は行いません。
  • 送信内容：対象の画像またはPDFそのもの（キャプチャした画像・選択範囲・ 指定したファイルや画像URLの中身）と、読み取りを指示する固定の文章です。 画像に写っているものはそのまま送信されますので、 個人情報が写り込む画像を扱う場合は十分にご注意ください。
    あわせて、1段目でAIが書き起こした文字も、2段目・3段目の問い合わせで同じ宛先へ送信されます （書き起こしを見ながら処方を組み立て、足りない項目を拾い直すためです）。
  • 画像の向きの判定：横向き・逆さに撮られた画像を正しい向きに直してから読み取るため、 画像の写しを、読み取りの前に送信して「時計回りに何度回すか」だけを尋ねます （長辺が1000ピクセルを超える場合は縮小した写しを、超えない場合はその画像を送ります）。 向きが決まらない場合は、向きを変えて読み取りをやり直すことがあります。 回転そのものはユーザーの端末内で行い、画像は保存しません。
  • 読み取りの手順：正確さのため、1枚の画像について 「①書き起こす → ②処方として組み立てる → ③足りない項目を拾い直す」の順で複数回問い合わせます。 いずれも同じ画像・同じ宛先（Gemini API）です。
  • API キーの扱い：ユーザー自身が取得したキーを使用します。 キーは常に HTTP ヘッダー（x-goog-api-key）で送信し、URL には含めません。 通信は HTTPS で暗号化されます。送信先のサーバーは日本国外に所在する場合があります。
  • 無料キー利用時の注意：無料枠のキーで利用する場合、送信内容が Google 社の モデル改善学習に利用される可能性があります。診療情報を扱う場合は、有料キーの利用および Google 社が提供する学習のオプトアウト設定を強く推奨します。
  • 送信されたデータの取り扱いは、Google 社の 「Gemini API 追加利用規約」 および「Google プライバシーポリシー」 に従います。

5-2. ユーザーが入力した画像URL

  • ユーザーが画像のURLを入力した場合に限り、そのURLへ画像を取りに行きます（取得のみ）。 宛先はユーザーが指定したものだけで、開発者が宛先を決めることはありません。

上記以外に、本拡張機能が外部へデータを送信することはありません。 薬剤名の照合に使う薬価基準収載品目リストは拡張機能に同梱しており、 照合のために外部と通信することはありません。

6. 医療機関でご利用になる場合の注意（重要）

本拡張機能は、処方内容（健康に関する情報）を扱います。 医療機関でご利用になる場合は、次の点を必ずご確認ください。

  • 画像に患者の氏名・生年月日・患者番号が写っている場合、 それも含めて Gemini API へ送信されます。 必要に応じて、氏名部分を隠す・範囲を指定して該当部分だけを読み取る、などの運用をご検討ください。
  • 所属機関の規程・個人情報保護方針・厚生労働省のガイドライン等に照らして、 外部のAIサービスへ画像を送信してよいかを事前にご確認ください。
  • 有料キーの利用と学習のオプトアウト設定を推奨します（第5章）。
  • 本拡張機能は入力までしか行いません。保存・確定は必ずご自身で行い、 入力後の内容を画面でご確認ください。

7. データの使用に関する誓約（Chrome ウェブストア開示事項）

  • ユーザーデータを第三者へ販売・譲渡しません （承認された利用目的と無関係な移転を行いません）。
  • ユーザーデータを本拡張機能の単一の目的と無関係な用途に使用しません。
  • ユーザーデータを信用力の判断や金融商品の販売目的に使用しません。

8. Google API ユーザーデータポリシー（Limited Use）への準拠

本拡張機能による Google API から取得した情報の使用および他アプリへの転送は、 Chrome ウェブストアのユーザーデータポリシー（Limited Use の要件を含む）に準拠します。

9. セキュリティ対策

  • APIキーの保護：設定画面の入力欄は常に伏せ字で表示し、 コピー・切り取り・右クリック・ドラッグ・選択を抑止しています（貼り付けは可能です）。 キーは端末内にのみ保存され、画面に表示されることはありません。
  • キーの送信方法：HTTPヘッダーでのみ送信し、URLには含めません。
  • リモートコードを実行しません：外部から取得したコードを実行する仕組み （eval や外部スクリプトの読み込みなど）を持ちません。 実行するのは拡張機能に同梱したコードのみです。
  • 同期しません：chrome.storage.sync は使用しないため、 設定やキーが他の端末へ同期されることはありません。
  • 保存・確定の操作を行いません：電子カルテ側で押す対象を、薬の候補と 用法の選択に限っています。まとまりを区切るために余白を押すときも、 ボタン・リンク・入力欄は避けるようにしており、「保存」「確定」「会計」などに 関わるボタンを押すことはありません。

10. ユーザーの権利（削除請求・開示請求）

本拡張機能は開発者側にデータを保持しないため、開発者が保有するユーザーデータはありません。 端末内のデータは、次の方法でユーザー自身がいつでも削除できます。

  • 設定画面で新しいAPIキーを入力して保存する（前のキーは上書きされます）
  • Chrome の拡張機能管理画面から本拡張機能を削除する （保存されたAPIキーと設定も、あわせて削除されます）

※ 設定画面の入力欄を空のまま保存した場合は、 「変更しない」という意味になり、保存済みのキーは消えません。 キーを完全に消すには、拡張機能の削除をご利用ください。

11. 利用にあたっての補足（正確性・医療安全）

本拡張機能は入力作業を補助するツールであり、診断・治療に関する判断や助言を行うものではありません。 AI による読み取りには誤りが起こり得ます。読み取った内容は、必ずご自身で元の紙と見比べて確認してください。 確認しないまま処方を保存しないでください。 薬剤名の照合（薬価基準収載品目リストとの突き合わせ）は打ち間違いに気づくための補助であり、 処方の妥当性を保証するものではありません。

12. ポリシーの変更

本プライバシーポリシーは、必要に応じて改定される場合があります。改定があった場合は、本ページの最終更新日を更新します。
